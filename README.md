# SIPANEN — Sistem Informasi Pertanian Berbasis Wilayah

SIPANEN adalah proyek platform web yang dirancang untuk membantu petani dan pemerintah daerah memperoleh informasi pertanian berdasarkan wilayah di Daerah Istimewa Yogyakarta.

## Latar Belakang

Informasi mengenai kondisi lahan pertanian, hasil panen, dan harga komoditas masih tersebar di berbagai sumber. Hal ini membuat pengguna kesulitan memahami kondisi pertanian secara menyeluruh dan mengambil keputusan berdasarkan informasi yang tersedia.

SIPANEN dirancang untuk mengintegrasikan informasi tersebut dalam satu platform berbasis web agar lebih mudah diakses berdasarkan wilayah.

## Tujuan Proyek

1. Menampilkan informasi kondisi lahan pertanian berdasarkan wilayah.
2. Menyajikan prediksi hasil panen berdasarkan data pertanian.
3. Menampilkan estimasi perubahan harga komoditas.
4. Memberikan informasi risiko gagal panen berdasarkan wilayah.
5. Membantu petani dan pemerintah daerah memahami kondisi pertanian untuk mendukung pengambilan keputusan.

## Target Pengguna

- **Petani:** memperoleh informasi kondisi lahan, prediksi hasil panen, estimasi perubahan harga komoditas, dan risiko gagal panen.
- **Pemerintah daerah:** memperoleh gambaran kondisi pertanian berdasarkan wilayah sebagai bahan pertimbangan dalam menentukan tindakan.
